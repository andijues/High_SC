# 架构与扩展

High_SC 不需要独立前端构建或数据库。FastAPI 仅在本机监听，原生网页通过带会话标记的本机接口操作任务。

```text
PDF 上传 → PyMuPDF 解析 → 段落/章节/图表 JSON
                         ↓
                   全文骨架与术语
                         ↓
               分批翻译、批注及原文高亮
                         ↓
               图表说明、校验、离线 HTML
```

| 位置 | 职责 |
|---|---|
| `highsc/pdf_parser.py` | 阅读顺序、段落、章节、图表裁切和参考文献 |
| `highsc/analysis.py` | 提示词、分层分析、输出模型和证据定位校验 |
| `highsc/provider.py` | 三种 HTTP 协议、认证、参数、解析与重试 |
| `highsc/codex_client.py` | 官方 CLI 调度、结构化输出、取消及临时文件清理 |
| `highsc/jobs.py` | 单工作线程、进度、缓存、暂停和恢复 |
| `highsc/storage.py` | 原子 JSON 写入、配置及本机密钥保护 |
| `highsc/renderer.py` | 原文、译文、批注及字体/PDF/图片的离线打包 |
| `highsc/server.py` | 本机接口、请求边界、上传和编辑 |
| `static/`、`templates/` | 工作台界面与离线阅读器 |

持久数据位于 `data/`，以论文 UUID 分目录。原文和模型输出分文件保存；高亮必须来自原文连续片段，图像路径不能被模型输出覆盖。暂未处理多人并发场景。

HTTP 模式不执行模型工具。Codex 模式使用临时、只读会话，禁用工具和网页搜索，不读取 CLI 的登录令牌；取消仅停止本次创建的进程。CLI 的功能标记可能随版本变化，兼容测试和版本说明应随更新维护。

增加专有渠道时，优先在 `provider.py` 添加独立适配与协议测试，避免把密钥或接口细节放进分析提示词。添加生成字段时应同时更新输出校验、Codex JSON Schema、编辑器和渲染器。模型不应改变原文、文件路径或执行系统命令。

环境变量 `HIGHSC_DATA_DIR` 可将测试或开发数据放在其他目录；`HIGHSC_ROOT` 指定资源根目录，通常不需要配置。
